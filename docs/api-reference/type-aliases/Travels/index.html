Travels<S, _F, A, P>

Persistence namespace, serialized history, and core timeline types.

Travels<S, _F, A, P> = object & A extends false ? object : object

Defined in: src/travels.ts:100

Public state-owning Travels capability surface.

Controlled journals expose recordPatches() through TravelJournal instead. Manual archive methods exist only when A is false, keeping unavailable operations out of both the type and runtime surface.

_F records the factory's enableAutoFreeze literal. No member depends on it, but it keeps its position so Travels<S, false> cannot silently start meaning a manual-archive timeline.

getState()

readonly getState: () => S

Borrowed live state, the same value observers receive as event.state.

Returns

S

Remarks

Typed as S so it can flow into stores and APIs that expect the state type, but it must be treated as read-only: history patches apply to this value, so mutating it outside Travels operations desynchronizes undo/redo. In immutable mode its objects are also the values of retained patches, so such a mutation rewrites the history that redo replays. enableAutoFreeze freezes every state Travels produces after creation.
