optional mutable: [F] extends [true] ? false : boolean

Whether to mutate the state in place (for observable state like MobX, Vue, Pinia) When true, apply patches directly to the existing state object When false (default), create new immutable state objects

Cannot be combined with enableAutoFreeze: true. TypeScript rejects the pair when the freeze flag is the literal true; the factories also reject it at runtime with INVALID_OPTION.
